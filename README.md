## The line

> I can stop time — but only during the split second my phone slips from my hand.

## How it works

`main.py` (stdlib only, deterministic) assembles the line from a `LINES` list, asserts it is 1–200 characters, and writes it to `/output/entry.txt`.

```bash
python3 main.py
cat /output/entry.txt
```
